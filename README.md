# O'zbek Alifbo Konvertori

Eski o'zbek lotin yozuvidagi matnlarni yangi o'zbek lotin alifbosiga avtomatik konvertatsiya qiladigan professional web application.

## 🚀 Xususiyatlar

### Asosiy funksiyalar
- ✅ **Real-time konvertatsiya** - Matn kiritayotganda avtomatik konvertatsiya
- ✅ **Fayl qo'llab-quvvatlash** - TXT, DOCX, PDF fayllarni yuklash
- ✅ **Export** - Natijani TXT va DOCX formatida yuklab olish
- ✅ **Drag & Drop** - Fayllarni sudrab tashlash
- ✅ **Dark/Light mode** - Tema almashtirish
- ✅ **Responsive design** - Mobile va desktop uchun optimallashtirilgan
- ✅ **Accessibility** - WCAG AA darajasida

### Conversion Engine
- ✅ **Normalization** - Unicode, whitespace, apostrophe normalization
- ✅ **Case preservation** - Katta/kichik harflar saqlanadi
- ✅ **Context-sensitive** - So'z ichida, boshida, oxirida to'g'ri ishlaydi
- ✅ **Exception dictionary** - 80+ maxsus so'zlar
- ✅ **URL/Email protection** - Konvertatsiya qilinmaydi
- ✅ **Number preservation** - Raqamlar saqlanadi

### Statistics
- ✅ **Conversion history** - So'nggi 100 ta konvertatsiya
- ✅ **Performance metrics** - Tezlik va samaradorlik
- ✅ **Dashboard** - Vizual statistika

## 🛠 Texnologiyalar

### Frontend
- **React 18** - UI framework
- **TypeScript** - Type safety
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **Framer Motion** - Animations
- **Lucide React** - Icons

### File Processing
- **Mammoth** - DOCX parsing
- **PDF.js** - PDF parsing
- **DOCX** - DOCX export
- **FileSaver** - File download

### Storage
- **LocalStorage** - Mahalliy ma'lumotlar saqlash

## 🎯 Ishlatish

### Matn konvertatsiya qilish
1. Matnni input maydoniga kiriting yoki faylni tashlang
2. Real-time mode'da avtomatik konvertatsiya bo'ladi
3. Natijani nusxalang yoki yuklab oling

### Fayl yuklash
1. "Yuklash" tugmasini bosing yoki faylni sudrab tashlang
2. Qo'llab-quvvatlanadigan formatlar: TXT, DOCX, PDF
3. Fayl hajmi limiti: 5MB
